# Dance Genre Classification

This is a classification algorithm that can classify keypoint data of body movements in dance videos into 2 different dance styles. The two dance styles it will classify are Jazz Ballet and House.



Here is the Project Structure:

cmse492_project/

    data/
        keypoints2d/          
        README.md   
    notebooks/
        01_exploratory_data_analysis.ipynb
        02_data_preprocessing.ipynb
        03_model_training.ipynb
        04_model_evaluation.ipynb
        05_hyperparameter_tuning.ipynb      
    models/
        model.pkl                  
        model_config.json      
        README.md                 
    reports/
        interim/                   
        final/                         
    requirements.txt             
    README.md                      
    .gitignore                   


The data can be downloaded from the keypoints2d folder. Then, you can run any of the notebooks! They are embedded, so if you want the final result, you can just run notebook 5 which runs the others in addition to itself.
